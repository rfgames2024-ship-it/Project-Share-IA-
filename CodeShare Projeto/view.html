Wiki ProjectShare+ IA: Lore IA

Made by Danpay Fonsek

The project's initial name was originally 'CodeShare.' It started as a project by an amateur developer who wanted to get into the world of AI. He created it to be used as an HTML teacher to teach beginners HTML (DO NOT GIVE READY-MADE SCRIPTS). The idea was discarded after the developer (me) realized that the type of AI was generic and decided to create a unique AI capable of turning dreams into reality. For projects that require extreme elaboration, it thinks and quickly creates the project along with the whole plan for how it can be carried out. It was made ready through an API and trained manually.
